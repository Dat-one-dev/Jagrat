# Jagrat - Quater of Human Conciousness

> Arise, awake, and learn by approaching the wise.

Jagrat is a new tab experience inspired by Indian Philosophy and designed to make the browser start page feel intentionally waking. 
 
Instead of opening on blank note it gives you a focused workspace with time, date, weather, search, music and some sanskrit verse. 

# How It Works???

Jagrat is a completely client side project.

The weather widget uses users current geolocation based on the extracted cordinates, It sents them to Open-Meteo API for current weather data and temperature. 


Search queries are sent directly to the selected search engine

The music player uses the browser's built-in audio support


# How to use it.

Either access the Vercel URL of Project or clone the repo locally and host a server by following commands

```bash
git clone https://github.com/Dat-one-dev/Jagrat.git
cd Jagrat
python -m http.server
```
